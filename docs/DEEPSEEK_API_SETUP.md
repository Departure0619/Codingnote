# DeepSeek 官方 API 配置指南

AI 是可选辅助。整理题目、保存代码版本、Docker 执行、手工错误原因、错题关联、规则建议、复习和备份均可在 AI 关闭时使用。

本指南优先介绍官方 API，是因为当前 `Tutor` 实现已对接 DeepSeek 官方地址，而非基于效果排名或免费承诺。当前状态为 **REAL_AI_PARTIAL**：配置界面和协议已实现，完整真实教学闭环尚未验收。本次发布准备没有发起真实模型请求。

## 1. 从官方渠道获取 Key

先阅读 [DeepSeek 官方首次调用文档](https://api-docs.deepseek.com/)，从该页的 API key 链接进入 [官方 API Key 页面](https://platform.deepseek.com/api_keys)，登录自己的账户后按平台实际界面创建 Key。只在自己的设备和账户中操作，不向他人发送凭据。

官方首次调用文档与定价页已于 2026-10-28 重新读取核对；未操作登录账户，不声称已验证登录后按钮名称或开户/充值流程。

API 可能收费，账户开通、余额及充值要求以平台实际显示为准。价格见 [官方模型与定价](https://api-docs.deepseek.com/quick_start/pricing/)，价格可能变化。本指南不抄写固定单价，也不承诺赠送额度或免费调用。

## 2. 在工作台保存配置

1. 打开“设置”中的 AI 辅导/模型与授权区域，选择“DeepSeek（需单独授权真实调用）”。
2. 选择服务端实际返回的模型。目前真实传输的可选模型限制为 `deepseek-flash`；目录虽还记录 `deepseek-v4-pro`，不能据此宣称普通用户可自由切换两者。
3. 在密码框填写自己的 Key。设置本次配置费用上限（美元）、请求等待时间和明确批准的请求次数。次数默认 **0**，新启动默认 **AI 关闭**。
4. 仔细阅读数据发送与费用提示；只有愿意承担相应费用时才勾选同意，再点击“保存 AI 配置”。安装检查无需启用 AI。
5. 保存成功后表单清空 Key、将次数输入恢复为 0 并取消勾选；服务内存中的已保存配置仍可能存在，这不等于关闭 AI。

保存配置不会测试连接，不会主动发送问题。修改配置时需重新填写 Key；空框不是“沿用旧 Key”。不要在题目正文、代码或聊天输入中填写 Key。

### 当前候选的预算限制必须先理解

界面输入控件允许请求次数 0–100、配置预算大于 0 且不超过 100 美元、超时 1–120 秒，但这只是表单/通用模型校验范围。真实传输另受 `round8_budget.validate_scope` 限制，仅接受 Flash，次数和费用不能超过历史受控验收范围。

代码里存在历史验收用的 **累计 8 次 / 0.50 美元** 限制；它不是面向新用户承诺的默认套餐、赠送额度或通用用户预算设计。虽然预算初始显示值可能来自这一历史设置，不能据此认为已获准调用或已付费。当前没有可自由设置任意累计上限的通用用户机制。

新安装不存在累计账本时，普通配置路径可建立本地授权账本，并非所有真实请求都必须先通过“受控复验”。但已有账本只允许收紧有效上限，保存、重启或换学习库不会清除累计消费和停止状态。不可通过删改/复制账本获取额度。

“受控复验授权”是另一条历史失败后的恢复路径，依赖固定审查材料、代码指纹和原始失败证据；公开包不包含这些材料，不能按普通用户开通按钮宣传，也不能指示用户补造这些文件。遇到历史停止或审查依据缺失应停止，保留记录，等待维护者处理。通用个人授权流程尚需另行决定和验收。

## 3. Key 实际存在哪里

| 阶段 | 实际行为与边界 |
|---|---|
| 填写时 | 密码框只遮挡显示；浏览器 DOM、FormData 和页面内存可短暂持有明文 |
| 保存时 | 通过本机 HTTP `PUT /api/ai` 发送给服务；不是加密凭据保险库 |
| 服务中 | 保存在当前进程的 `Tutor.key`；不作为配置字段写入学习 SQLite，也不读取旧 `.env` |
| 发请求时 | 后端使用 HTTPS 向 `https://api.deepseek.com/chat/completions` 发送，Key 在 Bearer 授权头中 |
| 清除 | 选择“关闭 AI”并保存，会清空服务当前 Key；保存模拟模式也清空；停止服务并重启后默认关闭且无 Key |
| 浏览器关闭时 | 服务可能仍运行，关闭标签页或清空表单不会清除后端 Key |
| 正在请求时 | 关闭/重新配置会设置取消标记，但工作线程已捕获的 Key 和已发往上游的请求可能继续存活至结束；不能保证立即撤回或免除费用 |

源码未见将 Key 写入 localStorage/sessionStorage 的配置路径；页面会把表单快照保存在内存中用于未保存提示。程序对当前 Key 有防误写与响应脱敏措施，但不能防止其他凭据、手工粘贴、恶意扩展、内存检查、系统转储或网络调试工具泄露。停用 Key 如需彻底撤销其调用能力，应在官方账户中按平台提供的方式撤销；本轮未验证该账户操作界面。

## 4. 辅导程度与模型是两组设置

全局及本题偏好包含辅导方式、提示、分析、总结、关联、频率、推荐练习难度、回答长度；有预设和自定义档位，本题可覆盖全局。基础帮助程度提供“提示优先 / 逐步辅导 / 直接解释”，单次提问还可选择直接讲解。

工作区辅导目标包括连续提问、生成错误原因候选、生成总结草稿。只共享用户选中的当前版本执行证据（最多 6 条）；默认不勾选执行证据，但题干、当前代码和相关历史仍属于上下文。隐藏测试仅发送状态，不发送其输入输出。模型候选需要用户核对，结构化事实检查也不等于全面事实验证。

回答长度影响输出 token 上限，分析/总结至少使用相应结构所需的上限；不能简单把“回答短”理解为固定费用。模拟模式仅返回固定流程文字，不能生成原因分析或总结。

## 5. 如何判断真正启用

核对设置状态中的模式、Key 是否配置、剩余批准次数、累计预算、停止原因和是否有请求未结束。状态显示“已授权”只代表本地条件，不能证明远端 Key 有效；`real_enabled` 也不验证余额、所有费用预留条件或远端权限。

需要实际辅导时，先保存版本，核对共享范围，再主动提交一个问题；这可能收费。一次真实回答成功并记录来源为 DeepSeek、连接状态为“上次请求成功”，才说明这次请求成功。模拟回答与隔离测试替身不构成真实验收。无需为检查安装而调用模型。

| 失败 | 建议处理 |
|---|---|
| 未配置/未授权/次数为 0 | 核对配置和同意项；默认关闭是正常行为 |
| Key 无效或无权限 | 在官方账户核对 Key，重新填写；不要把 Key 粘贴给维护者 |
| 余额不足、限流、模型不可用 | 核对平台账户与官方说明；本地存在停止状态时不可直接反复重试 |
| 超时、取消、服务错误 | 请求可能已发送并计费；先核对官方用量和本地未知费用预留 |
| 回复结构无效 | 问题保留，可能显示“未验证解释”；不会自动变成已确认原因或可保存诊断 |
| 累计授权停止/审查依据缺失 | 不通过保存设置或删账本绕过；等待维护者审查 |

应用不自动重试。取消不保证上游停止收费；有上游连接未结束时不能再并发发送。

## 6. 查看费用与避免非预期调用

设置里的“费用与额度”展示累计调用、已知费用估算、未知费用预留、有效累计预算和预估剩余；高级诊断保留授权和调用记录。记录位于学习库的 `ai_authorizations`、`ai_calls` 与应用根目录的 `.local/round8-ai-budget.sqlite3`，后者跨学习库使用，不保存 Key。

请求前按本地模型目录费率保守预留；返回有效 usage 后估算费用。未知用量继续占用预留并可能触发停止。`alpha/ai_models.json` 的费率快照标记核对日期 2026-10-27；本次另核对了官方定价页，但没有更新应用配置或验证真实账单。预估剩余不是官方余额，本地预算不能保证服务商实际扣款上限。

实际用量、余额和账单请在 [DeepSeek 官方平台](https://platform.deepseek.com/)登录核对；本轮未验证账户内具体账单菜单，也未确认账户是否提供硬预算开关，不虚构该能力。主动请求前核对授权范围，不用 AI 时关闭并保存；不重复点击失败请求；不要把应用对外开放。

Key 不能提交到 GitHub、写进代码、放入截图、录屏或聊天记录，因为他人获得后可能以你的账户调用并产生费用。公开前检查学习库、`ai_raw/`、备份、日志及截图，即使应用对当前 Key 有脱敏措施，也不能代替发布检查。
