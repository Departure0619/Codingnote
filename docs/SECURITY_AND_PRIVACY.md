# 安全与隐私

本工作台按本机单人使用设计，不提供完整安全审计或“数据绝不外传”保证。启动入口绑定 `127.0.0.1`、单 worker，后端校验 Host、部分修改请求的 Origin 和请求大小，前端有内容安全策略；这些措施不构成公网部署或本机恶意软件防护。

## API Key 的保护边界

Key 在密码框填写，通过本机 HTTP 交给后端，保存在当前 `Tutor.key` 进程内存中。外部调用使用 HTTPS Bearer 头。源码配置路径不把它写入学习数据库、URL 或浏览器持久存储，也不读取旧 `.env`。

保存关闭/模拟模式会清空当前服务 Key；重启默认关闭。清空表单、关闭浏览器、导出或备份均不能代替停止/关闭 AI。已经开始的工作线程和上游请求可能继续至结束，取消不保证立即清除所有内存副本、撤回已发送数据或免除费用。

应用会阻止部分包含当前 Key 的学习内容保存/发送，并对响应中的当前 Key 及其部分转义形式脱敏。这不是任意秘密扫描：其他 Key、个人资料、未预料编码和用户自行粘贴仍可能泄露。浏览器扩展、调试抓包、内存转储、本机权限过高的程序均超出这些措施的保护范围。

## 本地学习数据与备份

学习目录的 `learning.sqlite3` 含题目、代码、执行结果、聊天、错题原因、关联与复习等私人资料。实现使用普通 SQLite，未见应用层数据库加密或用户登录隔离。按操作系统文件权限保护目录。

完整 CLI 备份包含完整学习库，必须先停止服务，同时保存 `.sqlite3` 与同名 `.json` 清单；清单含源路径，转交前也需审查。它不包括学习目录的 `ai_raw/`、独立累计授权账本或 Docker 验收文件。网页脱敏导出移除部分隐藏内容和内部记录，但仍含题目、代码和学习历史，不是匿名证明，也不可用于完整恢复。

真实模型原始响应可能经脱敏后保存到 `ai_raw/`，供失败分析；模型可能复述题干或代码，应按敏感资料处理。累计费用/授权另在应用根 `.local/round8-ai-budget.sqlite3`，不要公开、删改以绕过门禁或把它当作可分发授权。

## 哪些内容可能发往外部 API

只有实际 DeepSeek 请求进入官方 HTTPS 传输；保存配置不探测连接。按 `teaching_protocol.model_context` 白名单，可能包含：

| 内容 | 范围 |
|---|---|
| 题目 | ID、标题、题干、来源 URL、修订号 |
| 当前代码 | 版本 ID、编号、语言、源码、摘要 |
| 本次问题与偏好 | 输入消息、辅导目标、帮助程度及部分表达偏好 |
| 相关历史 | 最多 12 条对话（问题、回答、版本/来源等）；若上下文包含，最多 4 个代码历史版本和 8 条错误原因记录 |
| 用户选择的执行证据 | 最多 6 条当前版本证据；可含 stdin、期望输出、stdout/stderr、状态、错误与备注（部分字段截断） |
| 隐藏测试证据 | 只发送允许的状态字段，不发送隐藏输入、期望输出或实际输出 |

默认不勾选执行证据，不能据此承诺不发送题干或代码。服务商会收到授权头中的 Key；不应将 Key 放进模型消息。没有源码依据证明服务商如何保留、训练使用或删除数据，这些规则应由用户在官方条款中另行核对。本轮没有验证服务商隐私条款或删除能力。

AI 关闭时，源码聊天路径拒绝外部模型请求；本地建题、版本、错题、关联、规则建议和复习仍可用。模拟模式只返回固定文字，不调用真实模型。来源识别不抓第三方网页；本地截图预览不上传，主动 OCR 则上传到本机服务，由本地子进程识别，源码声明不保留原图。可选 OCR 的真实安装与识别尚未验收，不作绝对隐私保证。

软件包下载、Docker 镜像拉取和用户主动访问外部链接仍可能产生网络流量，与 AI 开关无关。

## Docker 隔离的真实边界

运行前核验本机 Linux Engine、cgroup v2、seccomp、镜像和策略指纹、五语言验收证据。执行容器采用非 root、无网络、只读根文件系统、能力删除、no-new-privileges、资源及输出限制；不挂载整个项目、主机目录或 Docker socket 到运行容器。未就绪时拒绝执行，不回退到宿主机。

Docker daemon 本身拥有较强宿主权限，容器共享内核；这些限制不能承诺抵御所有逃逸或用于敌对多租户。仅按可信本机单人有限练习使用，不转发到公网/局域网，不把当前入口改成公开判题服务。

## 公开仓库应排除什么

- 实际 Key、`.env`、账户凭据、任何携带秘密的配置。
- `data/` 学习目录、SQLite 及 WAL/SHM、完整/脱敏备份、`ai_raw/`、累计授权账本。
- 私人运行日志、转储、截图、录屏、旧真实 AI 响应及授权收据。
- 原 20 题和隔离区资产、未授权外部题面/参考解/测试数据。
- 虚拟环境、可选 OCR 包/模型、Docker 二进制/镜像等未经单独许可核对的负载。

是否可发布应根据实际白名单和审查决定，不能只依赖 `.gitignore`。提交前也检查截图中的路径、账户与个人信息。不要向维护者提供凭据。

## 尚未完成的安全验证

没有完整渗透测试、独立安全审计、长期压力并发、公网多租户认证或所有平台验证。发布文件检查和离线测试不构成绝对安全保证。发现疑似泄露时先停用 AI，并在官方平台核对/撤销凭据；反馈时不要上传 Key、私人学习库、原始响应或含私人信息的截图。当前未设立专门的私密安全报告渠道。
