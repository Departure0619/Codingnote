错误原因、确认/待核对、关联决定、复习安排与自评是为展示构造的用户记录，不构成真实用户研究、教学有效性或全量正确性证据。所有 AI 保持关闭，当前状态仍为 **REAL_AI_PARTIAL**，没有 DeepSeek 调用、真实费用或模拟对话。
