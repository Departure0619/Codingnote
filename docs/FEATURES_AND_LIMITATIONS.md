# 功能与限制

下表基于公开候选源码及 2026-10-28 的历史定向验收报告。本文件说明源码能力与历史验收边界；本次发布准备的实际验证见 [发布检查](RELEASE_VALIDATION.md)。这里的“跨平台”首先指跨题目平台收集，不代表所有操作系统都已验证。

| 能力 | 状态 | 实际范围 | 证据与验证边界 |
|---|---|---|---|
| 多平台题目导入 | 已实现并有验证证据 | 手动录入；链接/文字识别 PTA、牛客、洛谷、LeetCode、Codeforces 的来源候选；支持手填其他来源 | HTTP 验证本地来源识别、手动编辑；浏览器验证手工导入。不是各平台题面抓取器，各域名/路径并非全部做过真人端到端验证 |
| 题目来源与知识标签 | 已实现并有验证证据 | 平台、原题号、URL、一级类型、二级标签；工作区可补充 | HTTP 验证来源与标签；许可字段只是声明，不能验证法律使用权 |
| 多语言工作区 | 已实现；执行需额外环境 | 五种注册语言均可保存代码，Docker 实际执行 | 五语言容器与 HTTP 记录有历史证据；无 Docker 仍可保存，不回退宿主机执行 |
| 代码版本与执行证据 | 已实现并有验证证据 | 保留旧代码，运行结果绑定版本与源码摘要；记录编译、输出、错误和状态；可录入外部反馈 | HTTP 验证绑定及旧版本不变，浏览器验证 Ctrl+S/刷新；外部判题记录由用户提供，单例通过不代表整体正确 |
| 错误原因记录 | 已实现并有验证证据 | 绑定版本、可选证据，区分候选/不确定/确认，保留修订 | HTTP 验证原因与错题关系；AI推断不能自动当事实 |
| 跨题关联 | 已实现并有验证证据 | 基于两条错误记录手工提出；核对快照、确认/拒绝/忽略/撤销，保留决策，依据变化可失效 | HTTP 验证合成关联；规则建议存在，不等于真实AI已可靠识别历史错误机制 |
| 错题管理与复习 | 已实现并有验证证据 | 笔记、标签、原始/修复版本、待复习、复习结果与本地建议 | HTTP、浏览器及恢复证据；不是完整记忆模型或外部推送服务 |
| AI 连续辅导 | 已实现，部分验证；需配置和网络 | DeepSeek 官方 API；默认关闭；模拟对话明确标识 | 真实 AI 仍为 REAL_AI_PARTIAL；本轮无真实调用，不据模拟证明教学有效 |
| AI 原因候选/总结草稿 | 已实现，部分验证 | 结构化输出、证据引用、用户编辑/确认/拒绝，部分事实冲突会阻断确认 | 真实总结编辑保存及部分 C++ 场景未验收；自由解释未全面事实核查；模拟模式不提供此能力 |
| 学习建议 | 已实现，部分验证 | 本地规则结合错题、标签、原因、关联决策和偏好生成建议，用户决定处理 | 基础复习链路有 HTTP 证据；未完成所有策略组合、长期学习效果评估 |
| OCR | 已实现入口；需额外环境，真实能力未验收 | 可选本地 RapidOCR；图片校验、识别草稿、人工核对后应用 | 主安装不含 OCR 包/模型；精确 wheel/模型许可、安装与真实识别未在候选验收 |
| 完整备份与恢复 | 已实现并有验证证据 | 停止服务后 CLI 导出完整学习 SQLite 和摘要清单，恢复到不存在的新库 | 历史真实进程重启与新目录恢复逐项核对；不是整个数据目录迁移，网页导出不可恢复 |
| 操作系统与设备 | 部分验证 | Windows 本机单人使用；Python 与浏览器页面具有跨系统实现基础 | macOS/Linux、其他浏览器、移动硬件未验收，不作全平台可用承诺 |
| 公网多人服务、自动平台同步 | 非当前支持范围 | 本机回环、单进程、单人；无自动题面抓取或提交同步 | 未提供公网多租户安全保证或压力并发验收 |

## 五语言实际执行能力

全部语言均要求本机 Docker 镜像构建及当前环境验收通过；不承诺 IDE、依赖管理或完整在线评测平台能力。

| 语言 | 镜像工具链 | 实际入口与边界 |
|---|---|---|
| Python | 3.12，补丁版本由真实验收记录 | 单文件，先语法检查，再以 `-I -S -u` 隔离参数运行；不包含用户第三方包安装 |
| C | GCC 14.2.0，C17 | 单文件 main，先编译，再独立运行产物 |
| C++ | G++ 14.2.0，C++17 | 单文件 main，先编译，再独立运行产物 |
| Java | Temurin 17.0.18+8 | 单源文件、无 package；优先 Main，否则唯一 public 类型/唯一顶层类；需标准 main 入口。入口及生成类文件名使用 ASCII；最多 128 类，产物传输上限 1 MiB |
| JavaScript | Node.js 22.22.0 | 单文件 CommonJS；先 `node --check` 再运行，可用内置模块，没有 npm 依赖 |

## 验收范围还不能覆盖什么

历史候选验收包含 15 项新增与 57 项保留测试、Chromium 6 项流程、HTTP 12 项检查、独立五语言 Docker 验收及恢复证据；它们覆盖层次有重叠，不能相加成覆盖率。本次发布准备验证见 [发布检查](RELEASE_VALIDATION.md)，未重新执行全部历史验收。
